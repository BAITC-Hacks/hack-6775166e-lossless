# Черновик issue: NVIDIA-проверка объяснения и сравнения

Адресат: `@neverexz` (Егор). Этот файл **не содержит ключ** и не подтверждает выполнение прогона.

## Цель

Подтвердить фактическое использование AI для обязательного объяснения рассчитанных изменений в задаче «Аким на 5 часов». Числа рассчитывает `src/simulator.py`; модель выбирает только ID готовых фактов в `src/explanation.py`.

## Задание Егору

- Исполнитель: `@neverexz`.
- Модель и версия: Егор выбирает доступный ID в NVIDIA API Catalog и записывает его в `NVIDIA_MODEL` и в issue перед прогоном. Не подставлять предполагаемое имя модели.
- Вход: фиксированный пример M7/Нура + M8/Нура + M10/Нура + M12/город + M5/Сарыарка и его лучшая одна замена M5/Сарыарка → M3/Нура. `scripts/check-model.py` проверяет объяснение одного плана; `scripts/check-model-comparison.py` передаёт модели оба полных расчёта и проверяет совет.
- Команда: в своём `zsh` выполнить `read -rs "NVIDIA_API_KEY?NVIDIA API key: "`, затем `echo`, `export NVIDIA_API_KEY`, `export NVIDIA_MODEL="<точный ID>"`, `python3 scripts/check-model.py`, `python3 scripts/check-model-comparison.py` из корня репозитория. Ключ в issue, чате и логах не публиковать.
- Число прогонов: два. Предлагаемый верхний предел расходов — **$1 суммарно**; Егор до запуска проверяет цену выбранной модели и остаток лимита и подтверждает этот предел в issue.
- Срок: до интеграционной проверки приложения; не откладывать к дедлайну сдачи.

## Результат

Записать ID модели, время прогона, `source`, `provider`, код выхода, Score и стоимость сценария; текст ответа без ключа можно приложить. Оба скрипта должны вернуть `source=model`, `provider=nvidia`, код выхода 0. Для одного плана Score `56.54307`, стоимость 95; для сравнения предложенный Score `57.20556`, стоимость 100. При `source=computed_facts` модельный прогон не подтверждён.
