# Проверка реального ответа OpenAI

23 сентября 2026 года владелица ключа добавила `OPENAI_API_KEY` и `OPENAI_MODEL` в локальный `.env`. Ключ не выводился в лог, чат или репозиторий. Все команды ниже выполнены на объединённой релизной ветке `agent/jury-release` с `OPENAI_MODEL=gpt-4o-mini` через OpenAI Responses API; для исключения приоритета NVIDIA при проверке заданы пустые `NVIDIA_API_KEY` и `NVIDIA_MODEL`. Это проверка локальной ветки до переноса в `main`.

| Сценарий | Команда | Наблюдаемый результат |
| --- | --- | --- |
| Один план: M7/Нура, M8/Нура, M10/Нура, M12/город, M5/Сарыарка | `NVIDIA_API_KEY= NVIDIA_MODEL= python3 scripts/check-model.py` | Код 0, `source=model`, `provider=openai`, стоимость 95, Score `56.54307`. Модель выбрала только вычисленные факты о вкладе мер, слабом районе, бюджете и лаге. |
| Сравнение с заменой M5/Сарыарка → M3/Нура | `NVIDIA_API_KEY= NVIDIA_MODEL= python3 scripts/check-model-comparison.py` | Код 0, `source=model`, Score `56.54307 → 57.20556`. В ответе явно указано снижение районного балла Сарыарки на `1,21`. |
| Вопрос советнику «Почему замена улучшает Score, но ухудшает Сарыарку?» | `NVIDIA_API_KEY= NVIDIA_MODEL= python3 scripts/check-model-advice.py` | Код 0, `source=model`, Score трёх вариантов `56.54307 / 57.20556 / 57.236735`. Ответ объяснил снижение районного балла Сарыарки на `1,21`; `selected_option` может быть `none` для сравнения или `one_change` для обсуждения замены. |

Дополнительно на финальном `main` задан вопрос «Помочь Нуре, не ухудшив Сарыарку». У обеих альтернатив балл Сарыарки ниже исходного; допустимые ID вариантов были ограничены `current` и `none` до запроса к модели. Живой ответ: `source=model`, `selected_option=current`; ответ показал, что лучшая замена улучшает Нуру на `2,02`, но снижает Сарыарку на `1,21`. План пользователя не изменился.

Сначала сравнение возвращало `source=computed_facts`: модель прислала коды показателей `S1/T2` вместо ID вычисленных фактов. После этого для OpenAI Responses введена строгая динамическая JSON-схема с допустимыми ID и сохранена серверная проверка. Повторный реальный вызов прошёл. При сбое API или нарушении схемы остаётся проверенный разбор `computed_facts`; Score всегда вычисляет симулятор. На этапе этой проверки набор `python3 -m unittest discover -s tests -q` содержал 41 тест и прошёл без ошибок.

Для проверки экспертом создайте `.env` из `.env.example`, только если `.env` ещё нет; существующий файл не перезаписывайте. Впишите личный ключ в `OPENAI_API_KEY` и выполните три команды выше. Без ключа приложение и числовой расчёт работают, а источник текста честно помечается `computed_facts`. NVIDIA интеграция есть, но сквозной успешный вызов не подтверждён; см. [журнал](model-run-issue.md).
