# Черновик issue: один NVIDIA-прогон AI-объяснения

Адресат: `@neverexz` (Егор). Этот файл **не содержит ключ** и не подтверждает выполнение прогона.

## Цель

Подтвердить фактическое использование AI для обязательного объяснения рассчитанных изменений в задаче «Аким на 5 часов». Числа рассчитывает `src/simulator.py`; модель выбирает только ID готовых фактов в `src/explanation.py`.

## Задание Егору

- Исполнитель: `@neverexz`.
- Модель и версия: Егор выбирает доступный ID в NVIDIA API Catalog и записывает его в `NVIDIA_MODEL` и в issue перед прогоном. Не подставлять предполагаемое имя модели.
- Вход: фиксированный пример M7/Нура + M8/Нура + M10/Нура + M12/город + M5/Сарыарка. Локальный скрипт `scripts/check-model.py` собирает запрос из рассчитанных фактов.
- Команда: в своём `zsh` выполнить `read -rs "NVIDIA_API_KEY?NVIDIA API key: "`, затем `echo`, `export NVIDIA_API_KEY`, `export NVIDIA_MODEL="<точный ID>"`, `python3 scripts/check-model.py` из корня репозитория. Ключ в issue, чате и логах не публиковать.
- Число прогонов: один. Предлагаемый верхний предел расходов — **$1**; Егор до запуска проверяет цену выбранной модели и остаток лимита и подтверждает этот предел в issue.
- Срок: до интеграционной проверки приложения; не откладывать к дедлайну сдачи.

## Результат

Записать ID модели, время прогона, `source`, `provider`, код выхода, Score и стоимость сценария; текст ответа без ключа можно приложить. Ожидается `source=model`, `provider=nvidia`, код выхода 0, Score `56.54307`, стоимость 95. При `source=computed_facts` модельный прогон не подтверждён.

## Приёмка агентом

Повторить `python3 -m unittest discover -s tests -v` и контрольный сценарий по README. Сверить, что модель не меняет Score и не добавляет чисел, отсутствующих в рассчитанных фактах. Только после этого отметить AI-вызов проверенным в README и закрыть issue.
