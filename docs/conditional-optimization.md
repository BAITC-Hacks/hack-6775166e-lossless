# Условная оптимизация городского портфеля

`src/optimizer.py` максимизирует **точную формулу Score из датасета** перебором
допустимых наборов, используя целые восьмые доли эффектов. Для официального
каталога это конечная задача из ровно пяти уникальных мер: бюджет не выше 100,
не более двух мер одного направления, район у районных мер, город без района,
три правила несовместимости. В целевой функции учитываются `clip(0, 100)`,
синергии, балл слабейшего района и штраф за каждое значение строго ниже 40.
Поэтому ценность меры зависит от уже выбранного набора; постоянная цена и
постоянная индивидуальная «полезность» не задают эту задачу.

## Два режима сверх глобального максимума

- `optimize(payload, required_choices=...)` сохраняет заданные меры **в тех же
  районах** и находит лучший допустимый комплект до пяти решений. При
  невозможности комплекта возвращает `ValueError`.
- `best_one_change(payload, current_choices)` принимает пять допустимых
  решений и ищет лучший портфель, который сохраняет как минимум четыре из
  них. Возвращает новый план, `previous_score`, `score_delta`, стоимость до и
  после и списки `removed`/`added`. Если улучшения нет, возвращает исходный
  план с нулевой дельтой.

На стандартный вход `src/optimizer.py` подаётся JSON-контракт из
`benchmark/optimizer_benchmark.py`. Поле `required_choices` включает режим
закреплённых решений, а `current_choices` — режим одной замены. Оба поля
одновременно недопустимы. Каждое решение записывается как
`{"id":"M7","district":4}`; для общегородской меры район — `null`.
При отсутствии обоих полей сохраняется исходный режим глобального поиска,
который использует приложение.

## Воспроизводимая проверка

Из корня репозитория, Python 3.10+, без API и внешних библиотек:

```bash
python3 -m unittest discover -s tests -v
python3 benchmark/optimizer_benchmark.py --self-test
python3 benchmark/optimizer_benchmark.py --scenario official --oracle --optimizer python3 src/optimizer.py
```

Тесты сравнивают условный максимум с **отдельной реализацией формулы** в
benchmark на официальных данных, пороге 40 и насыщении показателей. Для
рекомендации одной замены независимый тест проверяет все допустимые соседние
портфели. Это доказательство оптимальности в маленькой синтетической модели
ТЗ, а не прогноз реального эффекта городской политики.

На официальном проверочном наборе M7/Нура, M8/Нура, M10/Нура, M12/город,
M5/Сарыарка за 95 лучший портфель с **не более одной заменой** меняет
M5/Сарыарка на M3/Нура: стоимость 100, Score 57,20556 вместо 56,54307,
`score_delta = +0,66249`. Пользователь может принять или отклонить такую
рекомендацию; она не меняет ручной сценарий автоматически.
