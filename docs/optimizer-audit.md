Критический следующий шаг по скриншоту датасета: интегратор и владелец
AI-объяснения должны передать LLM **оба уже рассчитанных сценария** с
дельтами по каждому району и показателю, вкладом мер и синергиями; проверять
её ответ на опору только на эти числа; показать пользователю сравнение и
совет; подтвердить хотя бы один реальный модельный вызов по разрешённому
пути проверки. Точный оптимизатор остаётся числовым oracle, а не заменой LLM.
