# NVIDIA-проверка объяснения и сравнения

Адресат: `@neverexz` (Егор). Этот файл **не содержит ключ** и не подтверждает NVIDIA-прогон. Живой OpenAI-прогон обоих сценариев уже подтверждён отдельно в `docs/model-verification.md`.

## Цель

Подтвердить фактическое использование AI для обязательного объяснения рассчитанных изменений в задаче «Аким на 5 часов». Числа рассчитывает `src/simulator.py`; модель выбирает только ID готовых фактов в `src/explanation.py`.

## Задание Егору

- Исполнитель: `@neverexz`.
- Модель: `mistralai/mistral-nemotron`, выбранная из NVIDIA API Catalog. Перед повторным прогоном проверить её доступность для аккаунта.
- Вход: фиксированный пример M7/Нура + M8/Нура + M10/Нура + M12/город + M5/Сарыарка и его лучшая одна замена M5/Сарыарка → M3/Нура. `scripts/check-model.py` проверяет объяснение одного плана; `scripts/check-model-comparison.py` передаёт модели оба полных расчёта и проверяет совет.
- Команда: сохранить `NVIDIA_API_KEY` и `NVIDIA_MODEL` в `.env` корня запускаемого checkout, затем выполнить `python3 scripts/check-model.py` и `python3 scripts/check-model-comparison.py`. Переменные процесса имеют приоритет над `.env`, включая пустые значения. В выводе каждого скрипта проверить `provider=nvidia`; код 0 сам по себе подтверждает ответ любого настроенного провайдера. Ключ в issue, чате и логах не публиковать.
- Число прогонов: два. Предлагаемый верхний предел расходов — **$1 суммарно**; Егор до запуска проверяет цену выбранной модели и остаток лимита и подтверждает этот предел в issue.
- Срок: до интеграционной проверки приложения; не откладывать к дедлайну сдачи.

## Результат

Записать ID модели, время прогона, `source`, `provider`, код выхода, Score и стоимость сценария; текст ответа без ключа можно приложить. Оба скрипта должны вернуть `source=model`, `provider=nvidia`, код выхода 0. Для одного плана Score `56.54307`, стоимость 95; для сравнения предложенный Score `57.20556`, стоимость 100. При `source=computed_facts` модельный прогон не подтверждён.

## Приёмка агентом

Повторить `python3 -m unittest discover -s tests -v` и контрольный сценарий по README. Сверить, что модель не меняет Score и не добавляет чисел, отсутствующих в рассчитанных фактах. Только после этого отметить AI-вызов проверенным в README и закрыть issue.

## Фактические попытки 23 сентября 2026 года

- Ключ `NVIDIA_API_KEY` и модель `mistralai/mistral-nemotron` прочитаны из локального `.env` без вывода ключа. Первый контрольный запрос в 09:45:20 UTC завершился через 8,42 секунды с `source=computed_facts`, кодом 2, Score `56.54307` и стоимостью 95.
- Второй запрос в 09:49:28 UTC с таймаутом 30 секунд и лимитом 256 токенов завершился `TimeoutError`, кодом 2. Проверка адреса NVIDIA без ключа получила HTTP 405; это не подтверждает ответ модели.
- Диагностический запрос через OpenAI SDK 3.16.2 в 10:04:29 UTC получил ответ `mistralai/mistral-nemotron` через 19,986 секунды. Выбранные ID были допустимыми, но ответ содержал Markdown-блок с JSON, который прежний парсер не принял.
- После локального исправления парсера и перехода NVIDIA-клиента на SDK повторное воспроизведение этого ответа без сети дало `source=model`, `provider=nvidia`, Score `56.54307`, стоимость 95. Живой запуск `scripts/check-model.py` в 10:12:17 UTC завершился через примерно 38 секунд с `source=computed_facts`, кодом 2. Причина тогда не выводилась; теперь скрипт сообщает безопасные `error_type`, `http_status` и `elapsed_seconds`.
- Загрузка настроек из `.env` проверена без сетевого запроса: ключ и модель читаются, значение ключа не выводится. Успешный сквозной NVIDIA-вызов для одного плана и сравнения пока не подтверждён. Подтверждённые OpenAI-вызовы обоих сценариев описаны отдельно в `docs/model-verification.md`.
